Active Area Subtitles for Kodi

Keeps text subtitles inside the picture instead of the black bars of widescreen films.

In Kodi: Settings, File manager, Add source, enter this page's address. Then Add-ons, Install from zip file, choose that source and the repository zip below. Install Active Area Subtitles from the repository afterwards.
